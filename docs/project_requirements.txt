CURRENT MVP OVERRIDE (meeting decision, 13 November 2026): The older chat requirements below are superseded. WhatsApp-style messaging and WebSocket chat are dropped; forgot-password is dropped. User deletion must be soft deletion (retain the user row and linked data, set account_status='Deleted', and block access). Profile-photo storage remains undecided. User-to-user blocking is pending discussion against admin report-based moderation.

6. ⭐ Rating & Review — DECIDED

One review per completed session.

Session 3 → Review

The core decisions are now very well defined, but I would not yet call the entire feature set officially locked, because we should do one final consistency check—especially around Session Scheduling, Rating & Review, and Notifications—before we freeze everything.
